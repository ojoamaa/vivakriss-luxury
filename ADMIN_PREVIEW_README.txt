VIVAKRISS V1.4 - ADMIN PREVIEW

After deploying all files to GitHub Pages, visit:
https://ojoamaa.github.io/vivakriss-luxury-demo/#admin-preview

This is a public, browser-only DEMO, not a secure admin portal. Do not enter real customer information, financial data or payment evidence. Records do not sync across devices.

For production: authenticated FastAPI backend, PostgreSQL, server-side order/payment verification, protected media uploads and audit logs are required.

Deploy by uploading index.html and ADMIN_PREVIEW_README.txt; retain assets/ and .nojekyll.
